用一个密钥，接入你的应用

向管理员申请 API Key，在请求中发送 Authorization: Bearer <API_KEY>。密钥具备所属用户的访问权限和额度。

1. 查询可用音色


              

                返回数组中的 name 就是合成时要填的
                voice，
                is_default: true
                表示默认音色。使用完整名称，英文大小写需要一致；中文名称直接放在
                JSON 里，无需 URL 编码。
              

              
              

                下拉框列出当前可用音色；如果尚未配置，代码使用“播音女声”作为占位示例，请先查询并替换。
              

              
2. 指定音色：直接获取音频

              

              

                要换声音，只需修改 voice；text_lang
                控制文本语言，
                speed_factor 控制语速，两者都不会选择音色。省略
                voice 或设为 null 使用服务默认音色，
                默认音色由管理员在“音色与试听”中设置。
              

              

                以下为 Bash / zsh 示例；Windows PowerShell 请使用
                curl.exe，多行续行符使用反引号。 中文 JSON
                文件也可保存为 UTF-8 后使用
                --data-binary @request.json 发送。
              

              
3. 长任务：指定音色、查询进度、下载

              

              
MCP 服务入口

              

                使用支持 Streamable HTTP 和自定义请求头的 MCP 客户端。 将下方
                API_KEY
                占位符替换为管理员发放的密钥；沿用同一用户的额度、优先级和排队规则。
              

              
              

              

                工具：list_voices、get_my_limits、submit_synthesis、
                get_job、get_audio、cancel_job。
                提交后按任务号查询，完成后获取 WAV 音频内容；每次请求都需要 API
                Key，不提供管理员操作工具。
              

              

                先提交任务，随后每 1–3 秒查询状态；completed 后通过
                audio_url 下载。各次请求都需要 API
                Key。此方式适合通过 ALB 访问与多人排队。
              

              

                查询响应包含
                progress.stage、elapsed_seconds、分段计数及队列位置。
                进度阶段包括 loading_model、synthesizing
                和 encoding。 传入 cut_punc（如
                。！？）时，可查看引擎分段完成数；
                默认自动切分发生在模型内部，当前不提供单段推理的内部百分比。
              

              

                音色名称不存在返回 404；音色文件尚未准备好返回
                400，请联系管理员。
                /v1/voices 仅返回可用音色，不接受权重文件路径作为
                voice。 失败详情与 Python
                异常栈由管理员展开调用记录查看，普通 API Key 不具备查看权限。
